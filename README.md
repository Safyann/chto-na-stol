# Что на стол?

«Что на стол?» помогает выбрать настольную игру из своей коллекции. Введите число игроков, свободное время и отметьте, есть ли новички. Приложение предложит до трёх игр и объяснит, почему они подходят.

[Открыть приложение](https://safyann.github.io/chto-na-stol/)

## Попробовать

При первом запуске коллекция пустая.

1. В «Коллекции» добавьте свои игры. Укажите число игроков, длительность и подходит ли игра новичкам. Добавьте дату последней партии и шпаргалку, если они есть.
2. Откройте «Подборку», задайте условия вечера и нажмите «Подобрать игры».
3. Включите «Давно не играли», чтобы поднять игры с самой давней известной датой партии. Игры без даты идут после них.
4. Откройте карточку игры. После партии нажмите «Сыграли», чтобы записать сегодняшнюю дату.

Чтобы сыграть с дополнениями, сначала добавьте их названия в форму игры. Затем отметьте нужные дополнения в карточке. Кнопка «Сыграли» сохранит дату и состав партии. Пустой выбор записывает партию в базовую игру. Подбор использует число игроков, время и доступность для новичков, указанные у базовой игры.

## Запуск

Понадобится Node.js 22.13 или новее. Из папки проекта выполните:

```sh
npm ci
npm run dev
```

По умолчанию приложение откроется на [http://localhost:3000](http://localhost:3000). Если порт занят, Vite напечатает другой адрес. Данные хранятся в браузере для конкретного адреса. Сервер разработки и предпросмотр сборки по умолчанию используют разные порты и отдельные коллекции.

## Стек и архитектура

React 19, TypeScript, Vite и CSS Modules. Исходники организованы по Feature-Sliced Design. Страницы подбора и коллекции используют общую модель игры и карточку, а диалог просмотра и редактирования доступен из обоих разделов. [Устройство проекта](docs/architecture.md)

| Команда           | Назначение                                       |
| ----------------- | ------------------------------------------------ |
| `npm run check`   | Prettier, ESLint, Stylelint, TypeScript и Vitest |
| `npm run format`  | Форматирование исходников и документации         |
| `npm run build`   | Production-сборка и генерация сервис-воркера     |
| `npm run preview` | Локальный просмотр сборки                        |

[GitHub Actions](.github/workflows/ci.yml) запускает проверки и сборку при открытии и обновлении pull request, при push в `main` и вручную. Готовую папку `dist` можно скачать со страницы запуска как артефакт `chto-na-stol-pwa`.

## PWA и публикация

Выполните `npm run build` и `npm run preview`. Откройте приложение онлайн, дождитесь активации сервис-воркера, отключите сеть и перезагрузите страницу. Подборка, шпаргалки и отметка о партии доступны офлайн. В Chrome и Edge приложение можно установить из меню браузера.

После успешной сборки ветки `main` GitHub Actions публикует содержимое `dist/` на GitHub Pages. [Публикация через GitHub Actions](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages) · [Установка PWA](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)

## Импорт коллекции

В разделе «Коллекция» нажмите «Импортировать коллекцию» и выберите [collection.json](data/collection.json). В файле 41 игра со ссылками на карточки Hobby Games. Повторный импорт сохраняет правки к играм с теми же идентификаторами.

Для диапазонов времени взята верхняя граница. Если на странице указано «от N минут», в файле записано N как минимальный ориентир. Для Adventure Games: Подземелье взято время одной главы. Отметку для новичков можно уточнить в редакторе. [Adventure Games: Подземелье у издателя](https://www.kosmos.de/en/products/adventure-games-das-verlies)

Если раньше открывали приложение как файл, откройте тот же [index.html](index.html) в том же браузере, скачайте коллекцию и импортируйте её через ту же кнопку.
