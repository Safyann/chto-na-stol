# Что на стол?

«Что на стол?» помогает выбрать настольную игру из своей коллекции. Введите число игроков, свободное время и отметьте, есть ли новички. Приложение предложит до трёх игр и объяснит, почему они подходят.

## Попробовать

1. Откройте «Подборку». Для проверки оставьте четыре игрока, 60 минут и отметку «Есть новички».
2. Включите «Давно не играли», чтобы поднять игры с самой давней известной датой партии. Игры без даты идут после них.
3. Откройте «Диксит» и прочитайте шпаргалку о раскладке, первом ходе и правиле, которое легко забыть.
4. Нажмите «Сыграли» и откройте «Коллекцию». У игры появится сегодняшняя дата.

При первом запуске доступны 12 демоигр с примерными датами и три шпаргалки. В коллекции можно добавлять и редактировать игры, писать свои шпаргалки и убирать демоигры. Редактирование демоигры или отметка «Сыграли» оставляет её в личной коллекции.

Демонстрационные шпаргалки составлены по правилам издателей. [Диксит](https://www.libellud.com/game/dixit/) · [Just One](https://www.rprod.com/en/games/just-one) · [Лоскутное королевство](https://blueorangegames.eu/en/games/kingdomino/)

## Запуск

Понадобится Node.js 22.13 или новее. Из папки проекта выполните:

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Данные хранятся в браузере для конкретного адреса. Сервер разработки и предпросмотр сборки по умолчанию используют разные порты и отдельные коллекции.

## Стек и архитектура

React 19, TypeScript, Vite и CSS Modules. Исходники организованы по Feature-Sliced Design. Страницы подбора и коллекции используют общую модель игры и карточку, а диалог просмотра и редактирования доступен из обоих разделов. [Устройство проекта](docs/architecture.md)

| Команда           | Назначение                                       |
| ----------------- | ------------------------------------------------ |
| `npm run check`   | Prettier, ESLint, Stylelint, TypeScript и Vitest |
| `npm run format`  | Форматирование исходников и документации         |
| `npm run build`   | Production-сборка и генерация сервис-воркера     |
| `npm run preview` | Локальный просмотр сборки                        |

[GitHub Actions](.github/workflows/ci.yml) запускает проверки и сборку при открытии и обновлении pull request, при push в `main` и вручную. Готовую папку `dist` можно скачать со страницы запуска как артефакт `chto-na-stol-pwa`.

## PWA и публикация

Выполните `npm run build` и `npm run preview`. Откройте приложение онлайн, дождитесь активации сервис-воркера, отключите сеть и перезагрузите страницу. Подборка, шпаргалки и отметка о партии доступны офлайн. В Chrome и Edge приложение можно установить из меню браузера.

Для публикации загрузите содержимое `dist/` на статический HTTPS-хостинг. [Сборка Vite](https://vite.dev/guide/static-deploy.html) · [Установка PWA](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)

## Перенос из старой версии

Если раньше открывали приложение как файл, откройте тот же [index.html](index.html) в том же браузере и скачайте коллекцию. В новой версии откройте «Коллекция», нажмите «Перенести из старой версии» и выберите скачанный JSON. Если игра уже отредактирована в новой версии, сохранится новая запись.
